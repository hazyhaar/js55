Metrology in qualification

Isolate startup latency, idle memory footprint and host-call overhead are measured locally, but no cross-runtime comparison or benchmark number is published until it rests on named, reproducible benchmarks on identified hardware, with their date and conditions.

What is true today

The engine is pure Go and builds with CGO disabled. Isolates carry enforceable memory quotas and a CPU gas budget. The live REPL above reports the measured startup and execution time of each call it serves.

Architecture & Sandboxing Guarantees

Designed for untrusted code execution in autonomous agent workflows.

🛡️

Hermetic Memory Sandboxes

Each isolate is segregated in memory with hard byte quotas. A runaway allocation in one script is contained by its own quota rather than being allowed to exhaust the host process.

⏱️

CPU Fuel & Gas Limiting

Every instruction decrements a fuel counter. Infinite loops, recursive explosions, and ReDoS attacks are aborted deterministically.

🚀

Zero CGO / Pure Go Simplicity

Compiles into a single static binary. No external C++ libraries, Python bindings, or dynamic shared object dependencies.
