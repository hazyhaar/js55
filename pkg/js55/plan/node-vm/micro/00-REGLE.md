# Grain Gemini — un atome C

Une fiche = **une** fonction C++ déjà recopiée ci-dessous → **un** fichier `.c` ≤ 2000 jetons. Pas d’enquête, pas de Read du dépôt V8, pas de sgoiter dans la même fiche.

En-tête obligatoire :

```
// SPDX-License-Identifier: Apache-2.0 OR MIT
#include <stdint.h>
#include <stddef.h>
// CSG-001..004: NomCamel (/data/v8_upstream/src/...)
```

Interdit : Read, Grep, Glob, Maglev, éditer un `*_gen.go`. Un Write, verdict une ligne.
